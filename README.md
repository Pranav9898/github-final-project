# Simple Interest Calculator

This project is a simple interest calculator that calculates simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- Principal amount
- Rate of interest
- Time period

## Usage

Run the `simple-interest.sh` script and enter the required values when prompted.

## Project Purpose

The purpose of this project is to provide a simple command-line calculator for calculating simple interest using user-provided values.
